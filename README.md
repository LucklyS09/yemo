# 墨夜 · INK NOCTURNE

**一个只属于自己的本地小说创作空间。**

大纲、分级设定集和纯文本正文，收在一个安静、可长时间停留的界面里。没有账号，没有云端，没有订阅——故事就是硬盘上的普通文件。

`Windows 桌面版` · `本地优先` · `无需账号` · `无云端` · `MIT`

![墨夜总览](preview.png)

---

## 简介

写小说时，最常打开的地方其实只有三个：**大纲、设定、正文**。

大多数工具把它们拆进不同的页面、不同的账号，甚至不同的云服务里。墨夜反过来做：让这三件事待在同一个空间里，随时切换，随时保存，不打断写作。

它适合这样的作者：

- 想在一个安静、好看的界面里长期写一部长篇；
- 喜欢给人物、地点、物件单独建卡，并让名字在正文里自动带上颜色；
- 希望所有内容都留在自己电脑上，不依赖网络和账号；
- 不想被复杂的功能和写作方法论绑住。

## 功能

### 书架

- 按分类收纳小说，每个分类有自己的颜色点。
- 支持搜索、折叠分类、收起侧栏。
- 每本小说在硬盘上是一个独立文件夹，可以单独备份或整个拷走。

### 总览

- 封面、简介、分类、目标字数。
- 最近章节、写作进度、大纲速览、词条色卡。
- 一眼看到这本书写了多少、还差多少。

### 大纲

四种足够简单的结构，不强迫你填满每一格：

| 结构 | 适合 |
| --- | --- |
| 三幕式 | 建置 / 对抗 / 解决 |
| 起承转合 | 起 / 承 / 转 / 合 |
| 时间线 | 序章 / 开端 / 发展 / 高潮 / 结局 |
| 自由卡片 | 灵感 / 推进 / 冲突 / 余韵 |

- 可随时切换结构，已写的节拍会保留。
- 「载入灵感」会放入一组提示卡，可以随便改、随便删。

### 设定集

- 人物、地点、物件、概念等词条，支持三级层次。
- 阅读视图优先展示正文；编辑时属性展开在正文上方。
- 词条可以设置别名、类型、颜色、是否参与自动上色。
- 左侧目录支持展开 / 收起，词条多了也不会挤成一片。
- 可以按名字、别名、正文搜索词条。
- 显示词条在正文中的出现次数，以及出现在哪些章节。

### 正文

- **纯文本**：没有格式工具栏，不把时间浪费在调字号和缩进上。
- 输入停顿后自动保存，顶部有保存状态。
- 词条名字和别名自动上色，不弄乱光标，也不污染撤销记录。
- 正文上方的词条色卡可以快速跳转到对应设定。
- `Ctrl / Cmd + 点击` 正文里的彩色词条，直接打开它的设定。
- 专注模式：隐藏周围界面，只留下文字。
- 章节独立成文件，支持新建、重命名、删除。
- 统计全书字数与单章字数。

### 搜索

- `Ctrl + K` 打开全书搜索。
- 同时搜索正文、设定、别名和大纲。
- 结果可以直接跳到对应章节和文本位置。
- 输入 `/` 可以快速聚焦书架搜索。

### 数据安全

- 所有数据保存在本地，不上传云端。
- 小说、正文、设定、大纲都是可读的 JSON 文件。
- 自动保存之外，还有版本历史：
  - 编辑过程中每 5 分钟自动留一个快照，最多保留 30 个；
  - 也可以手动创建快照；
  - 可以恢复设定、大纲或单章正文。
- 删除的小说会进入「最近删除」，可以恢复或彻底清除。
- 支持导出 **Markdown 全书** 和 **JSON 备份**。
- 多个标签页同时编辑时，会提示冲突风险。

### 外观

- **暗色 / 亮色** 两套完整界面，不只是换背景。
- 四套主题：**松烟、夜潮、暮紫、麦金**。
- 六种背景：**星空、墨涟、经纬、远山、潮汐、薄雾**。
- 每个主题在明暗模式下有各自的饱和度、面板和文字色。
- 主题、背景和侧栏状态会记在本地浏览器里。

## 快速开始

### 安装版（推荐，不需要 Node.js）

在仓库的 **Releases** 页面下载：

```text
墨夜-Setup-x.y.z.exe
```

双击安装即可。

- 支持 Windows 10 / 11 x64。
- 安装包已经包含运行环境，目标电脑不需要 Node.js，也不需要联网。
- 安装后桌面和开始菜单会有「墨夜」，打开的是独立窗口，不经过浏览器。
- 数据保存在：`%APPDATA%\墨夜\data`
- 卸载不会删除这个目录，重装或升级后作品还在。

> 安装包目前没有代码签名，Windows 可能弹出 SmartScreen 提示；选择「仍要运行」即可。

### 源码版

需要 [Node.js 18+](https://nodejs.org/)。

```bash
git clone <your-repo-url>
cd ink-nocturne
npm start
```

Windows 也可以直接双击：

```text
启动墨夜.bat
```

浏览器会打开 `http://127.0.0.1:4173`。关闭命令行窗口，写作空间就停止。

源码运行不需要安装第三方运行依赖；只有构建桌面安装包时才需要 Electron 相关开发依赖。

## 数据与备份

源码版的数据在项目目录：

```text
data/
├── library.json
├── novels/
│   └── <novel-id>/
│       ├── meta.json
│       ├── outline.json
│       ├── settings.json
│       └── drafts/
│           └── <draft-id>.json
├── .history/
└── .trash/
```

安装版的数据在：

```text
%APPDATA%\墨夜\data
```

- `data/` 已被 `.gitignore` 忽略，不会误把作品提交到 GitHub。
- 备份时直接复制整个 `data` 文件夹即可。
- 从源码版迁移到安装版：把源码版 `data` 里的内容复制到 `%APPDATA%\墨夜\data`。
- 从安装版迁回源码版：反向复制即可。

## 技术实现

- **前端**：原生 HTML / CSS / JavaScript，无框架、无构建步骤。
- **后端**：Node.js 标准库 `http` / `fs`，没有生产依赖。
- **存储**：本地 JSON 文件，一个小说一个文件夹，一章一个文件。
- **词条上色**：CSS Custom Highlight API；不支持时退化为失焦后上色。
- **桌面版**：Electron 主进程内启动本地服务，`BrowserWindow` 加载页面；electron-builder 生成 NSIS 安装包。
- **服务地址**：只监听 `127.0.0.1`，不暴露到局域网。
- **端口**：默认 `4173`；被占用时自动往后找空闲端口。
- **安装包**：Electron 运行时、前端资源和 Node 服务一起打包，目标电脑无需额外环境。

## 构建 Windows 安装包

```bash
npm install
npm run dist
```

产物：

```text
dist/墨夜-Setup-<version>.exe
```

如果 `electron-builder` 下载二进制超时，可以设置镜像后再构建：

```bash
ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ npm run dist
```

Windows PowerShell：

```powershell
$env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
npm run dist
```

## 说明与限制

- 这是为**本地单人写作**做的工具，不是多人协作平台。
- 目前主要面向 Windows 桌面；源码版可以在其他支持 Node.js 的系统上运行。
- 正文是纯文本，不提供富文本排版、导出 Word 或 PDF。
- 版本历史是本地快照，不等于云备份；重要作品仍建议定期复制 `data` 文件夹。
- 安装包没有代码签名，首次运行可能触发 SmartScreen。
- 界面与文案均为中文；没有做多语言。
